# RF / Communication Systems Laboratory

A long-term engineering project focused on **communication systems, RF, SDR, DSP, radar, GNSS, FPGA, embedded systems, PCB design, and communication protocols**.

The goal is to move from **learning and simulation → implementation → hardware → complete system integration**.

## Areas

* 📡 Communication systems & digital modulation
* 🔌 Wired & wireless protocols
* 🧮 DSP, FFT, filtering, detection & matched filtering
* 📻 SDR & GNU Radio
* 🎯 Radar & signal processing
* 🛰️ GNSS
* 📐 RF, antennas & PCB design
* ⚡ STM32, embedded systems & FPGA
* 🛠️ Custom communication protocol design
